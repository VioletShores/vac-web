First Light — the one loop we're aiming at

We've stopped building toward vague "autonomy" and pointed everything at one loop that closes with no human in it — proof the architecture is real — then extend from there.

  • First light A — the command canary: you tap a Command Deck button → the sentinel senses it, acts, answers, flips this page — no chat session in the loop. Cleanest possible proof. ~2–3 weeks.
  • First light B — the WhatsApp defect loop: a real defect is sensed, scored, and fixed (or proposed to you with evidence) unattended. Useful autonomy. ~1–2 weeks after A.

Two hard rules from the multi-model review: it acts on objective defects, never on a vague "quality" score (which it could game); and it runs in propose-only mode until each fix type earns trust — auto-acting only on safe, reversible changes, never on anything that alters how it talks to a customer. Tonight's three quality lanes are already this loop's senses; the only net-new piece is the small reflex module, built once the sensory feed is live.
