# IETF Internet-Drafts

Two Internet-Drafts prepared for the same standards body that produced RFC 2748 — the COPS protocol deployed at meter scale. Both published July 2026.

## draft-zagarella-verified-human-root-00
**Verified Human Root Attestation** — rooting agent authority in a verified natural person. Defines the biometric ceremony, the authority token format, and the bounded delegation model. The technical specification for what VAC implements.

- IETF Datatracker: https://datatracker.ietf.org/doc/draft-zagarella-verified-human-root/
- Self-hosted copy: https://vacprotocol.org/papers/draft-zagarella-verified-human-root-00.txt

## draft-zagarella-autonomy-governor-00
**Pre-Action Risk-Graded Assurance** — human-on-the-loop autonomy governance. Defines the risk assessment, assurance-level ladder, and action-gate model. The technical specification for the proportional-assurance layer.

- IETF Datatracker: https://datatracker.ietf.org/doc/draft-zagarella-autonomy-governor/
- Self-hosted copy: https://vacprotocol.org/papers/draft-zagarella-autonomy-governor-00.txt
