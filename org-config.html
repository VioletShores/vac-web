Policy (COPS/PID)
COPS/PID governs which actions require which assurance tier. The minimum assurance floor set in Org Settings is the primary live policy control.
Minimum assurance floor — set above in Org Settings — is the authoritative per-org policy lever. It determines the lowest verification tier (none / quick / full) that COPS/PID will accept for any authorisation request within this organisation.

Fine-grained per-action policy rules (e.g. binding specific actions to full verification regardless of org floor) are available via the VAC API. COMING SOON — a policy editor will appear here in a future release.
ADVANCED POLICY RULES
Per-action assurance bindings, delegation rules, and custom COPS expressions are configured via the API (POST /v1/vat/governance/policy). This UI does not yet expose those controls — changes made here would be illustrative only and are intentionally disabled until the editor is production-ready.
To configure advanced policy now, use the REST API directly with a bearer token that has org:admin scope.
